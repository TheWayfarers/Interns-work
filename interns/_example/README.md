# Example Intern Folder

This is a sample — copy this structure, don't edit this folder.

```
interns/your-name/
├── README.md          ← intro about you
├── week-01/
│   ├── day-01.md      ← daily log
│   └── notes.md       ← learning notes
└── week-02/
    └── ...
```

See `week-01/day-01.md` for a filled-in daily log example.
