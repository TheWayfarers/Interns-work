- I learned Html Document Structure i.e, <!DOCTYPE html> - tells browser the document is of type html.
- <html> - the root element
- <head> - contains information about the page like title,css files, meta tags
- <body> - contains everything the user sees
- <heading> - used for heading
- <p> - used for text
- <a> - link
- href - tells the browser where to go
- <img src="" alt=""> - src - image location, alt -alternative text
- <ul> - unordered list
- <div> - a generic container used to group elements
- <section> - groups related content
- semantic tags - sematic tags tell what the content represents. ex: header,main,footer

CSS - used to style html
Linking CSS - <link rel="stylesheet" href="style.css"> - Tells html to use style.css
CSS Selectors - Element selector, Class selector (.), ID selector (#)
Box Model - Every Html element is considered as a box, contains Content, Padding, Border, Margin
Content - Represents Actual Text
Padding - Space inside the border
Border - the line around the content
Margin - space outside the element
Flexbox - used to arrange child elements in rows or columns
ex. main{
    display:flex;
}
