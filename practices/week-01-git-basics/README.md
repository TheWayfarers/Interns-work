# Week 01 — Git Basics

Complete these tasks in order. One PR per task.

---

## Task 01 — Setup your folder

**Branch:** `intern/<your-name>/setup`

1. Create `interns/<your-name>/README.md` with:
   - Your name
   - Start date
   - One line about what you want to learn
2. Commit and push
3. Open a Pull Request

---

## Task 02 — First daily log

**Branch:** `intern/<your-name>/day-01-log`

1. Copy `templates/daily-log-template.md` to `interns/<your-name>/week-01/day-01.md`
2. Fill it in for today
3. Commit, push, open PR

---

## Task 03 — Practice commits

**Branch:** `intern/<your-name>/day-02-commits`

1. Create `interns/<your-name>/week-01/notes.md`
2. Add 3 things you learned about HTML or CSS (or Git)
3. Make **2 separate commits** (add some content, commit, add more, commit again)
4. Push and open PR

---

## Task 04 — Fix a review comment

**Branch:** `intern/<your-name>/day-03-review`

1. After your mentor leaves a comment on one of your PRs, make the fix
2. Push the fix to the same branch (the PR updates automatically)
3. Reply to the comment when done

---

## Done with Week 01?

Move on to Week 02 when your mentor adds it to `practices/`.
