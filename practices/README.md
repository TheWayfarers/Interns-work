## How to use each module

Every task includes:

- **Learn** — concepts to understand
- **Task** — what to build or write
- **Submit** — file path + branch name
- **Reference** — example files to look at

## Rules

1. One PR per task
2. Work in `interns/<your-name>/` only
3. Add a daily log when you work
4. Track what you've covered in your `notes.md`
