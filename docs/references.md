Useful resources while working through tasks. Prefer **MDN** and **official docs** when stuck on syntax.

## Recommended course — Full Stack Open

**[Full Stack Open](https://fullstackopen.com/en/)** — free University of Helsinki course covering **React, Node.js, Express, REST APIs**, and modern JavaScript web development. Use it alongside our `practices/` tasks for deeper learning.

| Our module | Read on Full Stack Open | Link |
|------------|-------------------------|------|
| Web & JavaScript (background) | Part 0 — Fundamentals of Web apps | https://fullstackopen.com/en/part0 |
| React | Part 1 — Introduction to React | https://fullstackopen.com/en/part1 |
| React + APIs | Part 2 — Communicating with server | https://fullstackopen.com/en/part2 |
| Node.js & Express | Part 3 — Server with NodeJS and Express | https://fullstackopen.com/en/part3 |

**How to use it with this repo:**

1. Do the **task in `practices/`** first — submit your work here via PR
2. Read the matching **Full Stack Open part** to understand concepts deeper
3. Note what you learned in your `daily-logs/` and `notes.md`
4. **Start with [Part 0](https://fullstackopen.com/en/part0)** before Part 1 — it covers setup, course tools, and web fundamentals

Later parts (optional, when you're ready): Part 4+ testing, Part 6 state management, Part 7 custom hooks, etc. See the full [course contents](https://fullstackopen.com/en/#course-contents).

**Course home:** https://fullstackopen.com/en/

## How to use these

1. **Structured learning?** → follow [Full Stack Open](https://fullstackopen.com/en/) parts alongside `practices/` tasks
2. **Prefer video?** → see [Video references](#video-references-free) for the current topic
3. **Stuck on a task?** → open the link for that topic above
4. **Look up syntax?** → MDN reference pages
5. **Quick React/Node depth?** → Full Stack Open Parts 1–3
6. **Still stuck?** → ask mentor, mention what you tried and which link/video you watched

Add links you find helpful to your `notes.md` — share good ones with the team.
